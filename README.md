Electricity Bill Saving Advisor
A full-stack household energy-management platform for analysing electricity consumption, estimating bills, predicting electricity usage, and providing personalised energy-saving recommendations.

Overview: 
Electricity Bill Saving Advisor brings together household and appliance information, energy-usage records, billing data, and prediction services to help users better understand their electricity consumption and potential savings.
This was a team project. My primary contributions were backend API development, relational database integration, and connecting the backend with the machine-learning prediction service.

Key Features:
> Household, room, and appliance management.
> Electricity usage tracking and bill estimation.
> Budgets, goals, notifications, and tariff management.
> Electricity-consumption predictions and energy-saving recommendations.
> Authentication and protected API endpoints.

Technology Stack:
Area  |  Technologies
Frontend --> React.js
Backend	--> Java, Spring Boot, REST APIs
Database --> MySQL, Spring Data JPA, Hibernate
Prediction service --> Python, FastAPI, XGBoost
Additional integration --> OpenAI API
Authentication --> JWT
